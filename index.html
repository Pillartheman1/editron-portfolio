Editron: a Grok Bot I trained to edit video like I do

I built Editron on Grok Bot, xAI's agent app. Over nine days in October 2026, I acted as its editor and teacher, reviewing every version it cut for real clients.

What I did

  • Built and trained it on Grok Bot, giving written notes on every cut, take, grade and caption until each edit was approved.
  • Turned its mistakes into rules: a versioned rulebook plus automated pre-delivery checks, so the same miss doesn't happen twice.
  • Moved it into my DaVinci Resolve timeline with Grok Build. I transferred Editron's knowledge to Grok Build so it could learn from my real cuts, zoom keyframes and colour node tree instead of exported files. Its lessons fed back into Editron.
  • Shipped real client edits: Reels for a jewelry store and promos for a tech startup.
